# Agent Rules for This Repository

1. Commit policy
- After completing a coherent change set, create a local commit immediately.
- Do not leave finished work uncommitted.

2. Push policy
- Never run `git push` from this repository.
- Commits must stay local unless the user explicitly asks otherwise in a future task.

3. Language policy
- All user-facing CLI text must be in English.
- All code comments must be in English.
- All test names and test messages must be in English.
- If Russian text is found in code, comments, tests, docs, or prompts, rewrite it to English.

4. Quality policy
- Run tests and builds after non-trivial changes when tooling is available.
- Prefer small, reviewable commits with clear commit messages.
